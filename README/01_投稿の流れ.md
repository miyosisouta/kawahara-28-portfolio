# 01. 投稿の流れ

28卒のゲーム作品を一覧で見られるサイトです。
メンバー一覧からカードをクリックすると、その人の自己紹介と作品一覧のページが開きます。

サイト：https://miyosisouta.github.io/kawahara-28-portfolio/

---
<br>

## やること

自分の情報を書いた **`profile.json` と写真・画像データを、自分の名前のフォルダに入れて**、GitHub に投稿するだけです。

```
① 用意する     プロフィール・作品の情報・写真/画像データを準備
      ↓
② 作る         デスクトップに自分のフォルダを作り、profile.json と写真/画像データを入れる
      ↓
③ 投稿する     GitHub 上で自分用のコピー（フォーク）を作り、members フォルダにアップロード → プルリク
      ↓
④ 待つ         三好がチェックしてマージ → 数分でサイトに反映
```

## 完成するとこうなります

```
members/
  yamada-taro/          ← 自分のフォルダ（名前がそのままページの URL になります）
    profile.json        ← 自分の情報
    profile.jpg         ← 顔写真
    hobby.jpg           ← 趣味の写真
    talent.jpg          ← 特技の写真
    work-a.jpg          ← 作品のサムネイル（作品の数だけ）
    work-b.jpg
```

## 気をつけること

- **クローンしない**：Fork（アプリ）や `git clone` は使わず、**ブラウザ（GitHub のサイト）だけ**で投稿する
- **GitHub の「Fork」ボタンは使う**：サイト上に自分用のコピーを作る機能で、Fork（アプリ）とは別物
- **自動翻訳はオフ**：翻訳されるとボタンの名前が変わり、手順書と見比べにくくなる
- **アップロードは `members` フォルダの中で**：外に置くとサイトに表示されない
