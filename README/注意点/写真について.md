# 写真について

サイトは**誰でも見られる公開ページ**で、採用担当の方も見ます。写真を選ぶときは次の点に気をつけてください。

---

<br>

## 写真ごとのポイント

サイトでは、写真が決まった比率に**自動で切り抜かれます**。大事なものが端にあると切れてしまうので、**真ん中**に入れてください。


### 顔写真（profile.jpg・縦長 3:4）
- **顔が上の方の真ん中**に来るように撮る（上に合わせて切り抜かれるため）
- **胸から上**が写るくらいがちょうどいい。全身や遠くから撮った写真だと顔が小さくなる
- **正面向き・明るい場所・背景はシンプル**に。採用担当が見るので、清潔感のある写真を
- 横長の写真は左右が大きく切れるので、**縦向きで撮る**

### 趣味・特技の写真（hobby.jpg / talent.jpg・横長 4:3）
- 伝えたいもの（道具・作ったもの・やっている様子）を**真ん中**に
- サイトでは小さめに表示されるので、**何の写真か一目でわかる**ものを選ぶ

### 作品のサムネイル（work-a.jpg など・横長 16:9）
- **ゲームの一番見せたい場面**のスクリーンショットがおすすめ
- 端に文字や UI があると切れることがあるので、**大事な部分は真ん中**に
- タイトル画面より、**プレイ中の画面**の方が内容が伝わりやすい

## 使ってはいけない写真

| ✕ 使わない | 理由 |
|---|---|
| ネットで拾った画像 | 著作権の問題があります |
| アニメ・ゲーム・漫画のキャラクターの画像 | 著作権の問題があります |
| 芸能人や他の人の写真 | 肖像権の問題があります。友達が写っている場合も、本人の許可を取ってください |
| LINE・Discord などのスクリーンショット | 他の人の名前や会話が写ってしまいます |
| 住所・学籍番号などが写っている写真 | 個人情報が公開されてしまいます |

**○ 使ってよいもの**：自分で撮った写真、自分で作った画像、自分の作品のスクリーンショット

> **⚠ 一度アップロードした写真は、あとで消しても GitHub の履歴に残ります。** 公開して困る写真は、最初からアップロードしないでください。

## ファイル名のルール

- JSON に書いたファイル名と、実際の写真のファイル名を**完全に同じ**にする
  - `.jpg` と `.png` の違い、大文字と小文字の違い（`profile.JPG` と `profile.jpg`）にも注意
- 拡張子だけを書き換えない（`profile.png` の名前を `profile.jpg` に変えるだけ、はダメ）
  - png の写真なら、JSON の方を `"profile.png"` に合わせる
