## 自分の情報

| 項目名 | 内容 | 例 |
|---|---|---|
| `name` | 名前（漢字）。姓と名の間は半角スペース | `"山田 太郎"` |
| `nameRomaji` | 名前（ローマ字）。名 → 姓の順 | `"Taro Yamada"` |
| `photo` | 顔写真のファイル名 | `"profile.jpg"` |
| `jobs` | 希望職種（下の10個から**最大3つ**。**第1希望から順に**） | `["グラフィックス", "UI"]` |
| `comment` | ひとことコメント（「」は付けない） | `"描画処理を突き詰めるのが好きです"` |
| `githubUrl` | 自分の GitHub のページ | `"https://github.com/yamada-taro"` |
| `hobby` | 趣味（`text` に内容、`photo` に写真のファイル名） | `{ "text": "キャンプ", "photo": "hobby.jpg" }` |
| `talent` | 特技（書き方は趣味と同じ） | `{ "text": "けん玉", "photo": "talent.jpg" }` |
| `qa` | 自由な質問1つと、その答え | `{ "question": "もし宝くじが当たったら？", "answer": "最強のPCを組む" }` |
| `works` | 作品の一覧（下の「作品の情報」） | |
| `hidden` | 通常は `false`。サイトに出したくないときだけ `true` | `false` |

<br>

## 希望職種

次の10個の中から選び、**表記を1文字も変えずに**コピーして使ってください（1文字でも違うと、他の人とタグの表記がそろわなくなります）。

```
グラフィックス
テクニカルアーティスト
ゲームプレイ
AI
物理・当たり判定
エンジン開発
ツール・エディタ
UI
ネットワーク・サーバー
企画・レベルデザイン
```

- 最大3つ。**同じ職種を2回以上書かない**
- 1つ目が第1希望。サイトでもこの順に並びます

## 作品の情報（作品ごとに）

| 項目名 | 内容 | 例 |
|---|---|---|
| `title` | 作品名 | `"スライムの冒険"` |
| `genre` | ジャンル | `"3Dアクション"` |
| `thumbnail` | サムネイル画像のファイル名 | `"work-a.jpg"` |
| `platforms` | 使ったエンジン・ライブラリ（下の表記を参考に） | `["自作エンジン", "DirectX 12"]` |
| `teamSize` | 制作人数（**数字**。1人なら `1`） | `4` |
| `role` | 担当した内容。**1人制作なら空欄 `""`** | `"プレイヤー制御、当たり判定"` |
| `period` | 制作期間（「制作期間：」は付けない） | `"3か月"` |
| `pageUrl` | 作品の個人サイトの URL。**まだなければ空欄 `""`** | `"https://〇〇.github.io/〇〇/"` |

`platforms` は自由に書けますが、よく使うものは次の表記にそろえてください。

```
自作エンジン
DirectX 11
DirectX 12
OpenGL
Vulkan
Unity
Unreal Engine
```

※「自作エンジン」はサイト上で緑の枠で目立つ表示になります。この表記のまま書いてください。

## 写真

| 写真 | ファイル名 | 縦横の比率 | おすすめのサイズ |
|---|---|---|---|
| 顔写真 | `profile.jpg` | 縦長 3:4 | 600×800px |
| 趣味の写真 | `hobby.jpg` | 横長 4:3 | 800×600px |
| 特技の写真 | `talent.jpg` | 横長 4:3 | 800×600px |
| 作品のサムネイル | 自由（例：`work-a.jpg`） | 横長 16:9 | 1280×720px |

- 比率が違っても自動で切り抜かれますが、**端が切れる**ので、なるべく比率に合わせてください（顔写真は上に合わせて切り抜かれます）
- 写真は**すべて必須**です
- 1枚あたり **500KB 以下**が目安です（重いとサイトの表示が遅くなります）
- `.png` でもOKです。その場合は JSON のファイル名も `"profile.png"` のように合わせてください

> **⚠ ネットから拾った画像・アニメのキャラクター・他の人の写真は使わないでください。** サイトは誰でも見られる公開ページです。
> 詳しくは → [注意点/写真について.md](注意点/写真について.md)
