==============================================================
  28卒 ゲーム作品ポートフォリオサイト　投稿の手引き
==============================================================

このフォルダには、サイトに自分のプロフィールと作品を載せるための
説明がまとめてあります。

  サイト　　：https://miyosisouta.github.io/kawahara-28-portfolio/
  困ったとき：3年の三好まで


--------------------------------------------------------------
■ 読む順番
--------------------------------------------------------------

  1. 01_投稿の流れ.md
       全体の流れ（何をして、どうなるか）。まずはこれだけ読んでください。

  2. 02_準備するもの.md
       プロフィール・作品・写真など、先に用意するものの一覧。

  3. 03_GitHubでの操作.md
       フォルダを作ってから、GitHub に投稿するまでの操作手順。
       ※ 投稿するときは、これを横に開きながら進めてください。

  4. 注意点 フォルダ
       うまくいかないとき、投稿する前の最終チェックに。


--------------------------------------------------------------
■ ファイルの説明
--------------------------------------------------------------

  README.txt
      このファイル。どれから読むか、どれが何のファイルかの案内。

  01_投稿の流れ.md
      投稿の全体像。完成するとフォルダがどうなるか。

  02_準備するもの.md
      profile.json に書く項目、希望職種の選択肢、作品の情報、写真のサイズ。

  03_GitHubでの操作.md
      フォルダ作成 → profile.json の記入 → フォーク → アップロード
      → プルリク、と、投稿後に直したいときの手順。

  注意点/JSONの書き方.md
      profile.json の各項目に何を書くか。完成見本の画像つき。

  注意点/写真について.md
      写真ごとの撮り方のポイント、使ってはいけない写真、ファイル名のルール。

  注意点/よくあるミスと直し方.md
      これまでに実際に起きたミスと、その直し方の一覧。


--------------------------------------------------------------
■ 一番大事なこと（3つだけ）
--------------------------------------------------------------

  ・リポジトリをクローンしない（Fork アプリは使わない）。ブラウザだけで投稿する
  ・アップロードは、自分のコピーの「members」フォルダの中に入ってから行う
  ・出す前に、プルリクの「Files changed」でファイルの場所を確認する
